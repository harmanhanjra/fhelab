FHE Lab

Fully-Homomorphic Encryption over the polynomial ring ℤ[x]/(xⁿ+1) — run entirely in your browser.
Encrypt it, compute on it, decrypt the result. This lab implements a toy BFV-style scheme: you encrypt numbers with a public key, perform addition and multiplication on the ciphertexts without ever seeing the plaintext values, then decrypt with the secret key. Watch each coefficient's noise, scale Δ, and the degree-2 tensor product that a multiplication produces. ⚠ Educational only — tiny parameters, toy PRNG, zero dependencies (native BigInt, vanilla JS).

public key pk₀ (size n)— await keygen —
pk = (−a·s − e, a). Anyone can encrypt; only s decrypts.

2Encrypt

ciphertext (c₀, c₁)— await encryption —
c₀ = pk₀·u + e₀ + Δ·m , c₁ = pk₁·u + e₁. Δ = ⌊q/t⌋.

3Homomorphic computation

computed ciphertext— await computation —
⊕ is componentwise; ⊗ is a degree-2 tensor product (c₀₀,c₀₁,c₁₁) decoded with s².

Live run

Encrypts two values, computes m⊕m₂ and m⊗m₂ on ciphertexts, decrypts both. The real product is m·m₂ mod t.

ℤRing ℤ[x]/(xⁿ+1)

xⁿ ≡ −1— await —
Coefficients wrap with an alternating sign: coefficient i+j lands in slot (i+j) mod n, negated on wrap (xⁿ≡−1). This keeps a "polynomial noise" that cancellation can tame.

ΔPlaintext scale

scale— await —
Placing m at magnitude Δ·m leaves room for the additive noise ±(e₀−e·u+s·e₁) to stay under Δ/2, so rounding recovers m.

⊗Multiplication tensor

(c₀₀, c₀₁, c₁₁)— await —
Multiplying c=(c₀,c₁) and d=(d₀,d₁) gives (c₀d₀, c₀d₁+c₁d₀, c₁d₁). The phase now involves s² — a degree-2 ciphertext.

🔑Wrong key

garbage— await —
A different secret s' produces a phase dominated by noise — the plaintext is unrecoverable. This is the security property (RLWE).
